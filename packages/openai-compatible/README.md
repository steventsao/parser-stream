# @parser-stream/openai-compatible

An HtmlStream plugin for any OpenAI-compatible server.

vLLM, Ollama, LM Studio, or a hosted API of the same shape. Two prompt modes: markdown, or the ParseBench layout contract. These servers read images, not PDFs.

Part of [parser-stream](https://github.com/steventsao/parser-stream): stream a document into clean, sanitized, semantic HTML, block by block, with your own key or your own plugin. See the repository for the design and for how to write a plugin.
