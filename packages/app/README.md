# @parser-stream/app

Live sessions and the HTTP + SSE transport for parser-stream.

One app over the core: an upload page, a redirect to a document page, replay from any event, and a plain UI. The core emits the same events for any other transport.

Part of [parser-stream](https://github.com/steventsao/parser-stream): stream a document into clean, sanitized, semantic HTML, block by block, with your own key or your own plugin. See the repository for the design and for how to write a plugin.
